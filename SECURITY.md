# Security reports

Do not disclose secrets, participant identities, live reserve addresses or exploitable private details in public issues.
Use [GitHub private vulnerability reporting](https://github.com/artel-red/artelvpn-lab/security/advisories/new).
If the form is unavailable, withhold sensitive material until a maintainer provides a verified private channel.

This repository currently contains research prototypes. No production service or security warranty is implied.
Useful scope includes authentication assumptions, unsafe experiment execution, data disclosure, workflow permissions and publication boundaries.
The project does not promise a fixed response time before a staffed security process exists.
