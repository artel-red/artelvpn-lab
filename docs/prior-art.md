# Предшествующие работы

- Lantern уже использует bandit для выбора протоколов/путей: https://lantern.io/en/circumvention и https://github.com/getlantern/flashlight/blob/main/dialer/bandit.go.
- Отложенные результаты и промежуточные наблюдения: https://proceedings.mlr.press/v119/vernade20b.html.
- Amoeba: https://arxiv.org/html/2310.20469v1 — лабораторное формирование потока, не показатель обхода России.
- Maybenot: https://github.com/maybenot-io/maybenot — защита от анализа формы трафика.
- WATER: https://www.petsymposium.org/foci/2024/foci-2024-0003.php — сменяемые транспортные модули.
- CensorLab: https://censorlab.cs.umass.edu/ — исследовательская эмуляция механизмов.

Ни одно из этих направлений само по себе не является новым изобретением ArtelVPN.
Наша первая эвристика пока не показала существенного общего преимущества; отрицательный результат сохранён.
