# Данные

По умолчанию — синтетические нагрузки и публичные агрегаты. Пользовательская история, plaintext и реальные ключи не нужны.
Запрещены публичные pcap/pcapng пользователей, подписочные ссылки, контакты, точные места и графики тестировщиков, IP действующих входов.
Даже шифрованная трасса может раскрывать адреса, имена и временные связи. Удаление payload не равно обезличиванию.

До полевого опыта отдельно определяются согласие, поля, срок хранения, отзыв участия, доступ и способ удаления.
Публичный отчёт проходит проверку агрегации и происхождения. Данные вклада не считаются истинными только из-за подписи автора.
Не используйте реальные токены как примеры. Для адресов — документационные диапазоны, для имён — `.test`.
Большие модели и наборы данных принимаются только после проверки происхождения, прав, содержимого и ресурсоёмкости.
