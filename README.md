# ArtelVPN Lab

Открытая лаборатория воспроизводимых исследований свободного доступа к сети.
Public research workspace for reproducible censorship-resilience experiments.

**Статус:** исследовательские прототипы и абстрактная модель ограничений.
Доказанного нового обхода ТСПУ, готового VPN-клиента и измерений российских операторов здесь пока нет.

**Зачем:** проверять идеи, сохранять отрицательные результаты и находить эффективные методы подключения без сбора истории посещений.
**Тип:** открытое исследование для ArtelVPN. **Лид:** @olerast67.
**Команда:** сопровождающие назначаются владельцем; внешние участники работают через Issues и fork/PR.
**Срок:** этапы заданы Milestones; даты полевого пилота ещё не назначены.

## Начать

```shell
python -m unittest discover -s tests -v
python -m unittest discover -s research/controller-v0 -p "test_*.py" -v
python tools/check_publication.py
python research/controller-v0/benchmark.py --seeds 8 --sessions 120 --output /tmp/artel-benchmark
```

Python 3.12+, стандартная библиотека; активные сетевые пробы не выполняются.
В Windows для последней команды выберите свой временный каталог вместо `/tmp`.

## Структура

`lab/` — абстрактная модель фильтров и синтетические сценарии.
`research/` — исследовательские реализации и результаты с обозначением уровня доказательств.
`rfcs/` — проверяемые предложения. `tests/` — локальные проверки.
`tools/` — проверка разрешённого состава публикации.

Задачи — Issues, этапы — Milestones. Обсуждения открыты для идей; изменения кода проходят PR и review.
Никакие секреты, действующие входы, личные трассы и данные тестировщиков не нужны для вклада.
Секреты в публичный issue не отправляйте: [private security report](https://github.com/artel-red/artelvpn-lab/security/advisories/new).

## Решения

- Публичная и внутренняя работа находятся в отдельных независимых репозиториях.
- Публичный CI не получает внутренних секретов, артефактов и исполнителей.
- Автоматического переноса из закрытой области нет.
- Имитация механизма фильтрации не считается точной копией ТСПУ.

Собственный код и документация — MIT; сторонние материалы доступны по ссылкам и не перелицензируются этим репозиторием.
